# Multibooting OS X, macOS, Windows and Linux

## Introduction

This section covers the installation and management of a multiboot system using OpenCore as the primary boot manager.

The supported operating systems are:

- **Legacy OS X (10.6 - 10.12)** using HFS+
- **Modern macOS (10.13 - 26)** using APFS
- **Windows 10/11** using NTFS
- **Linux distributions** using ext4 or btrfs

> [!NOTE]
>
> The distinction between **OS X** and **macOS** in this guide is intentional.
>
> It refers not only to Apple's naming change in 2016, but also to the different installation methods introduced with macOS High Sierra.
